# 试玩自检清单

每次改动后按这张表走一遍，10 分钟内能发现大部分回归。命令都在仓库根目录。

## 0. 自动化（必须全绿）

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1 test                    # 130 个 C++ 单测（Windows）
wsl bash -lc "cd /mnt/d/Code/DSH/*Game* && ./build.sh test"                # 同上，WSL / Linux
wsl bash -lc "cd /mnt/d/Code/DSH/*Game* && ./build.sh smoke"               # 服务端真实 TCP 端到端
wsl bash -lc "cd /mnt/d/Code/DSH/*Game* && ./build.sh bench 12"            # 节奏跑分 + 门禁
bash tools/run_godot_tests.sh                                              # 客户端 51 + 56 项断言
```

## 1. 启动链路

- [ ] 双击 `run-demo.cmd`：服务端先起（本机 Windows，2 秒级）、客户端 3 秒内连上
- [ ] 服务端没起时，客户端开始页显示「未连接服务端 · 正在重试」
- [ ] 开始页四个阵营按钮点哪个，中间就列哪家的 10 张牌
- [ ] 「开始游戏」→ 构筑界面 → 选 8 张 → 「开始对局」

## 2. 对局内

- [ ] 开局镜头对准自己的基地（不是地图中心）
- [ ] 手牌 4 张、牌堆显示剩余 4；抽牌有飞入动画、出牌有飞出动画
- [ ] 点手牌 → 点地图：能放下建筑，并出现工地进度条
- [ ] 12 秒后建筑完工，听到「完工」音效
- [ ] 兵营开始自动出兵（按兵种 5~20 秒一个），工程站出工程兵
- [ ] 资源条随产出入账；领地显示 22 左右
- [ ] 滚轮缩放（1.0~4.0）、右键拖动、点小地图跳转；**WASD 不再移动镜头**
- [ ] 「拆除」开 → 点自家建筑/塔能拆掉（拆塔不再强制「至少留一座」）
- [ ] 「成长树」开 → 整页显示 12 个节点，科技不够时按钮是灰的
- [ ] 占点后领地上涨，建筑上限跟着变（`clamp(4 + 领地/10 + 经济枢纽, 4, 11)`）
- [ ] 3 分钟后（或 `--fast` 1 分钟后）「总部支援」可点，点地图有爆炸音效

## 3. 结束与重开

- [ ] 打到只剩一家 → 结算页：标题/原因/四家血量/两个按钮，**不重叠**
- [ ] 「再来一局」能直接开下一局
- [ ] 「换卡组」回到构筑界面
- [ ] `ESC` 暂停：继续 / 返回主菜单 / 退出游戏
- [ ] `M` 静音切换有 toast 提示

## 4. 美术/音效替换

- [ ] `python tools/gen_art.py` 后跑 `godot --headless --editor --quit --path client/godot`
- [ ] 截图确认地形/单位/建筑/基地都换成新素材
- [ ] 删掉某张图 → 该元素回退到色块，不崩
- [ ] 删掉某个 wav → 该音效静音，不报错
