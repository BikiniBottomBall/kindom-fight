# ADR 0010：大图、领地资源、总部支援、昼夜天气、四套阵营卡池

- 状态：已采纳
- 日期：2026-11
- 关系：在 ADR 0008（随机地图/资源点）和 0009（AI 抢点）之上继续扩展。

## 背景

这一轮要解决的是"**人人能玩、能打完整一局**"，不是再堆模拟指标：

1. 地图还是太小，四个出生点之间跑一趟就十几秒。
2. 资源只有四类，且都来自自家建筑/资源点，缺少"地图控制"这个维度。
3. 对局没有后期手段：一旦僵持就只能等时间到。
4. 四个阵营只是被动不同，卡池完全一样 —— "选阵营"没有实感。

## 决策

### 一、地图 3600×2400（45×30 格）

面积是上一版的 1.56 倍。配套：基地血量 2800（沿用）、行军速度 135%、后期产出翻倍。

### 二、第五种资源：领地（territory）

只能靠**占住地图资源点**慢慢攒：每个点每 3 秒给 1 点。

- 买不了兵、盖不了房 —— 它唯一的用途是**呼叫总部支援**。
- 所以它是"地图控制"的度量：占得越久，越有资格掀桌子。

### 三、总部支援（对地打击）

- 打到 **25 分钟**（`hq_unlock_seconds`）解锁；花 **30 点领地**发动；20 秒冷却。\n- 领地价格和时间都能通过 `MatchConfig` 覆盖：`--fast` 是 60 秒解锁，测试里用 1 点领地验证链路。
- 效果：**全图任意点**砸一发，半径 320 内对**所有敌人**造成 900 伤害
  （单位/塔/建筑），基地暴露时受到双倍。
- 各阵营的文案不同（先锋"轨道炮击"、商会"空袭"、教团"灵能风暴"、蜂群"生物弹"），
  但数值一致 —— 先保证公平，再谈差异化。
- 目的不是加内容，是给僵持局一个**确定的结束手段**：领地够、时间到，就能强行拆掉一家。

### 四、昼夜 + 天气

- **昼夜**：2 分钟一个循环，周期过半入夜。夜里索敌/塔射程 **-15%**，客户端整张图压一层冷色。
- **天气**：开局 40 秒后开始变化，每 40~70 秒随机换一次（晴/雨/雾/风暴）：
  - 雨：移速 -10%
  - 雾：索敌 + 塔射程 -25%
  - 风暴：移速 -5%
- 全部由 tick 和种子决定 → 仍然"同输入同结果"。

### 五、四套阵营卡池（每套 7 张）

选阵营 = 选卡池，**不能混拿**。服务端在 `start()` 里直接校验：卡片的 `alliance` 和玩家的阵营不符就开局失败。

| 阵营 | 3 张单位 | 3 座建筑 | 1 张法术 |
|---|---|---|---|
| 先锋军团 | 盾卫 / 长枪 / 攻城车 | 物资站 / 兵营 / 能源站 | 轨道炮击 |
| 联合商会 | 民兵 / 骑手 / 弓手 | 物资站 / 兵营 / 能源站 | 应急治疗 |
| 灵能教团 | 弓手 / 巨兽 / 长枪 | 物资站 / 兵营 / 研究所 | 冰霜 |
| 蜂群 | 民兵(3) / 长枪 / 骑手 | 物资站 / 兵营 / 能源站 | 战吼 |

**AI 也必须跟着改**：原来的 AI 写死了卡牌 id（0=民兵、14=战吼…），换阵营后它根本认不出自己的牌，
灵能教团胜率一度只有 **2%**。现在 AI 一律按 `CardDef` 的类型在自己手牌里找，不再认 id。

### 六、快速模式

25 分钟才解锁的机制，在 2 分钟的测试局里永远看不到。所以：

- `kingdom_fight_server --fast`：对局 180 秒、总部支援 60 秒解锁。
- bench 用 150 秒 / 60 秒。

## 数值（bench，150 秒压缩局）

```
位置: 22.5 / 24.5 / 22.5 / 23.0   平 7.5%
平均 71.1 秒；首次淘汰 36.4 秒；超时 16.5%；83.5% 只剩一家
联盟: 先锋 18.8% / 商会 20.4% / 教团 10.1% / 蜂群 42.1%
```

## 已知问题（没藏）

1. **蜂群明显偏强（42%）**。它的卡都是"一张牌多个兵"，而新加的占点机制恰好奖励人数
   （人多占得快、地图收入高），两者叠在一起就滚起来了。下一步要么削它的出兵数，要么让占点更看"兵种质量"。
2. **教团偏低（10%）**。它的强度在巨兽和法术上，但 bench 的压缩局只有 60~90 秒，
   高级兵还没成型就打完了。长局里应该更好，但没验证。
3. 地图变大了，但寻路还是"直线 + 卡住兜底"，AI 有时会绕远路。

## 代价

| 项 | 说明 |
|---|---|
| 协议又变了 | 卡池多一个阵营字节、快照多领地/天气/昼夜/总部状态、`MatchStart` 多解锁时间 |
| 5 个资源 + 天气 + 总部 | HUD 信息密度明显上升，需要新手引导 |
| 25 分钟解锁 | 正常一局 2 分钟就结束了，玩家很可能永远见不到总部支援 —— 所以必须靠 `--fast` 或长局配置来体验 |

## 复审条件

1. 蜂群 > 32% → 削它的单位数量或价格。
2. 教团 < 15% → 给它的单位换一个更便宜的前排。
3. 总部支援的发动率 < 5%（bench）→ 领地攒得太慢，调 `kTerritoryPerNodeTicks`。
