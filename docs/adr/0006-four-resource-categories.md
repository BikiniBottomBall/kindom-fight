# ADR 0006：四种资源归为同一层级（人力 / 物资 / 能源 / 科技）

- 状态：已采纳
- 日期：2026-11
- 关系：**取代 ADR 0005 的资源命名与结构**（数量仍是 4，机制做了合并 + 新增）。

## 背景

ADR 0005 的四资源是「兵源 / 食物 / 铁 / 科技」。跑起来之后发现两个问题：

1. **抽象层级不齐**：兵源和科技是"能力/池"，食物和铁是"具体某样物资"。
   卡牌上同时出现"8 食物"和"10 铁"时，玩家会问：凭什么长枪吃铁、民兵吃食物？
2. **题材不搭**：四个星际联盟在抢一颗星球，"铁"太中世纪。玩家第一反应就是"改成矿源吧"。

## 决策

统一成四个**同一层级**的库存：

| 资源 | 定位 | 来源 | 管什么 |
|---|---|---|---|
| **人力** | 可部署的人口（有上限、会恢复） | 基地 + 兵营（每座 +40 上限） | 出兵节奏 |
| **物资** | 通用材料（口粮、零件、合金都在里面） | 基地 + 物资站 | 一切建造与出兵 |
| **能源** | 电力/燃料 | 基地一丝 + 能源站 | 高级单位与**所有法术** |
| **科技** | 研究点 | 研究所 | 解锁攻城车 / 巨兽 / 火雨 |

配套建筑改名并合并：

| 旧 | 新 | 说明 |
|---|---|---|
| 农场 | **物资站** | 原"食物"并入物资 |
| 矿井 | **能源站** | 原"铁"的位置改产出能源 |
| 兵营 | 兵营 | 不变 |
| 研究所 | 研究所 | 不变 |

卡牌价格重排：

- 单位：`人力 + 物资`（便宜兵只吃这两样）
- 攻城车 / 巨兽：额外吃 `能源`，巨兽再吃 `科技`
- 法术：全部吃 `能源`，火雨额外吃 `科技`

## 为什么不是直接改名

只把"铁 → 矿物"是最小改动，但解决不了"层级不齐"：
兵源和科技依然是"能力"，另外两个依然是"某样东西"。
**合并食物+铁、补一个能源**之后，四个都是同一种东西：*一个会被消耗的库存*。
代价是少了一条"先建农场还是先建矿井"的二分决策，换来的是**一眼就懂的四栏、以及一条新的能源门槛**。

## 代价（诚实记账）

| 项 | 说明 |
|---|---|
| 少一个运营决策 | 原来食物/铁各有产线，现在物资一条线；补位的是"能源站什么时候建" |
| 能源门槛偏后 | 所有法术都要能源，所以没能源站就打不出任何法术 —— 这是有意的，但新手会先撞墙（已缓解，见下） |
| 数值要重调 | 合并后物资消耗翻倍、能源成为新瓶颈，整轮 bench 重跑（见下） |

## 数值（300 局 AI vs AI，固定 AI 种子）

```
P0 19.3%  P1 27.3%  P2 23.3%  P3 25.7%   平 4.3%
对局时长 平均 124.4 秒（最短 22.8，最长 240）
首次淘汰 平均 51.6 秒
82.7% 以"只剩一家"结束，17.3% 超时
```

> 位置胜率还有 19%~27% 的差：把随机种子换成固定种子后差距没消失，
> 说明更像是"某个 AI 性格偏强"而不是位置本身。没继续挖，先记在这。

### 第一局体验：基地能源 + 推荐卡组

原版的能源门槛对新人太硬：不建能源站就几乎放不出法术，而新人第一局往往连牌都还没认全。
两处缓解（不改资源结构）：

1. **基地基础能源 1/12 tick → 1/9 tick（1.7 → 2.2 / 秒）**：不建能源站也能慢慢攒出一发治疗/战吼，
   能源站的价值从"能不能放技能"变成"放得快不快"。
2. **加「一键选推荐」卡组**（`民兵 / 骑手 / 物资站 / 能源站 / 兵营 / 治疗`）：
   2 个兵 + 3 座建筑 + 1 个法术，第一局就能同时体验运营和技能。
   `--autodeck` 用的也是这套。

## 复审条件

1. 超时 > 25% → 把 120 秒的产出翻倍提前，或降基地血量。
2. 能源成为唯一瓶颈（每局都在抢能源站）→ 给基础产出加一点能源。
3. 位置胜率差 > 10 个百分点 → 换 AI 种子做对照实验，确认是性格还是位置。
