# ADR 0012：兵速降 30%、开局 60 秒、高战略点 5 分钟点亮、随机事件

- 状态：已采纳
- 日期：2026-11
- 关系：调整 ADR 0011 的速度与节奏，并新增随机事件/点亮机制。

## 背景（来自实际试玩的四个反馈）

1. **"小兵移速太快"** —— 上一版为了大地图把全局行军速度提到 150%，玩家看到的是小兵在屏幕上窜。
2. **"我的资源牌还没好就死了"** —— 开局 40 秒 AI 就压过来，运营牌还没落地就进防守。
3. **"容易卡在中心湖对质，谁都死不了"** —— 没有寻路，两队兵隔着水面对面站死。
4. **"高资源点 5 分钟后高亮"** —— 高战略点应该有个"开闸"时间，而不是一开始就能抢。

## 决策

### 一、兵速降 30%（直接改单位数值，不是改倍率）

| 单位 | 之前 | 现在 |
|---|---|---|
| 民兵 / 长枪 | 80 | **56** |
| 盾卫 / 弓手 / 巨兽 | 60 | **42** |
| 骑手 | 160 | **112** |
| 攻城车 | 40 | **28** |

全局倍率固定在 100%：**速度只写在一个地方**（单位数值表），改倍率会让"为什么这个兵快"变得无法解释。

### 二、开局 60 秒：AI 只运营、只防守

AI 现在有 `kOpeningTicks = 60 秒`：这段时间里它照常铺经济、照常回防，但**不主动出击**。
玩家因此有整整一分钟把资源牌摆下去。

同时开局资源提高：人力 60→80、物资 40→60、能源 20→30。

### 三、卡住的兵会绕行

单位新增 `stuck_ticks`：连续 20 tick（1 秒）没有位移，就沿"目标方向的垂直方向"横着走 220 像素，
然后重新判断。用来打破"两队兵隔着中心湖面对面站死"的僵局。

### 四、高战略点 5 分钟后点亮

- 高战略点开局是**暗的**（画面上是灰的），**不能占、不产出**。
- `tick >= 5 分钟` 自动点亮，之后才能抢。
- 客户端用 `flags` 字节区分：bit0 = 已激活，bit1 = 爆发中。

### 五、随机事件（自己定的）

开局 60 秒后开始，每 75 秒来一次，两种事件各 50%，**完全由 tick + 种子决定**（可复现）：

| 事件 | 效果 |
|---|---|
| **补给空投** | 随机一家立刻 +60 物资 +30 能源（客户端横幅提示） |
| **矿脉爆发** | 随机一个资源点 60 秒内产量翻倍（点外面套一圈金色脉冲） |

## 数值（bench，240 秒上限）

```
平均 166.4 秒（上一版 121.2）；首次淘汰 101.3 秒（上一版 55.8）；最短一局 82.3 秒
超时 28.7%；位置 19.3 / 24.7 / 26.7 / 18.0
阵营 先锋 26.6% / 商会 20.1% / 教团 9.9% / 蜂群 32.1%
```

**"资源牌还没好就死了"这条解决了**：最早的一局也是在 82 秒才有第一家出局，
开局 60 秒内没有任何一家会被拆。

## 代价 / 未解决

| 项 | 说明 |
|---|---|
| 超时 28.7% | 兵慢了、图大了，最后两家更难碰上。需要靠后期机制（总部支援）收尾 |
| 教团 9.9% | 依旧偏弱：它的强度在巨兽和法术，而一局 2~3 分钟打不到那个阶段 |
| 绕行是权宜之计 | 真正的解法还是 A*（见 ADR 0009 的两次失败记录） |
