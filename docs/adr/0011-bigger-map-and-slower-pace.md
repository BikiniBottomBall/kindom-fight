# ADR 0011：地图再放大一倍、节奏整体放慢

- 状态：已采纳
- 日期：2026-11
- 关系：调整 ADR 0010 的地图尺寸与节奏参数。

## 背景

两条反馈：

1. **"地图怎么没有扩大？"** —— 尺寸确实从 2880×2080 改到了 3600×2400，但客户端一直把整张图缩进窗口：
   图越大缩放比越小，屏幕上观感一模一样，单位反而更小。这是**镜头的问题**，不是地图的问题。
2. **"AI 玩得太快"** —— 一局 70 秒就打完，前期运营几乎没有存在感。

## 决策

### 一、地图 4800×3200（60×40 格）

面积是上一版的 1.78 倍。配套：

- 出生点最小间距 900 → **1400**，资源点簇心/间距同步放大。
- 行军速度：先把全局倍率提到 150% 试了一版，**看下来小兵跑得太赶，又收回 100%**（即单位数值表里的原始速度）。\n  地图变大后宁可让行军久一点，也不要让画面上一堆小兵窜来窜去。
- 地形生成的林地/高地/碎石数量随面积增加，湖更大。

### 二、加镜头（这是"看起来变大"的关键）

- **默认放大 2.2×**（相对整图适配比例）。4800 的地图如果按整图适配，单位只有几个像素。
- 滚轮缩放 1.0×~4.0×，以光标为中心；右键/中键拖动、WASD/方向键平移；
  界面上加了 **＋ / － / 全图** 三个按钮，键盘 `+` `-` `0` 也能用。
- 右下角**小地图**：整张地形 + 各家基地 + 当前视野白框，点一下直接跳过去。

### 三、放慢节奏

| 项 | 之前 | 现在 |
|---|---|---|
| 基地人力 / 物资 / 能源 / 科技 | 1/5 · 1/6 · 1/9 · 1/60 | 1/7 · 1/8 · 1/12 · 1/80 |
| 物资站 / 能源站 / 兵营 / 研究所 | 1/3 · 1/6 · 1/2 · 1/6 | 1/4 · 1/8 · 1/3 · 1/8 |
| AI 决策间隔 | 0.4 秒 | **0.7 秒** |
| AI 开局期（只运营不出击） | 无 | **前 40 秒** |
| 基地血量 | 2800 | **5200** |
| 后期产出翻倍 | 60 秒 | 120 秒 |

## 效果（bench，240 秒上限、120 秒解锁总部支援、行军 100%）

```
平均 121.2 秒；首次淘汰 55.8 秒；超时 20.7%
位置 24.0 / 24.0 / 25.3 / 20.7 —— 随机出生点下仍然很平
阵营 先锋 21.0% / 商会 24.2% / 教团 11.2% / 蜂群 37.2%
```

实机（客户端 + 3 个 AI，--fast）观察：20 秒时四家满血、场上只有零星几队兵；
55 秒左右人类位（机器人代打）先被拆掉，随后另外两家连锁出局。

## 为什么只慢了 30 秒，不是慢成 10 分钟

基地血量从 2800 抬到 5200，平均时长只从 98 秒涨到 105 秒 —— 说明**决定胜负的不是拆基地，而是第一次会战**：
一方赢下会战后滚雪球，剩下三家在 30 秒内连锁倒下。

要让一局真的打到 5~10 分钟，得动更根本的东西（任选其一）：

1. 单位造价大幅提高（人口/物资 ×1.5），让"输一场会战"不等于"直接出局"。
2. 塔和基地带范围溅射，让兵海不好推进。
3. 给防守方一个"复活/重建"机制（比如基地被打掉后还能撑 60 秒）。

这三条都会改变游戏手感，需要单独一轮迭代，不塞进这次改动里。

## 代价

| 项 | 说明 |
|---|---|
| 大地图 + 镜头 | 多了一套相机操作，新手要学（界面已加提示和按钮） |
| 节奏变慢 | 一局从 70 秒变成约 105 秒，但离"25 分钟总部支援"的设想还差很远 |
| 蜂群仍偏强 | 37.8%，占点机制依然奖励人数 |
