# ADR 0013：真正的 A* 寻路、全场伤害 -25%、开始页与暂停菜单

- 状态：已采纳
- 日期：2026-11
- 关系：取代 ADR 0012 里"卡住就横切"的权宜绕行；把 ADR 0009 记录的两次寻路失败正式收尾。

## 背景（试玩反馈）

1. **"路径有问题，容易卡在中心湖对质，谁都死不了"** —— 之前单位只会"直线 + 墙滑行"，
   碰到大湖就贴着岸走，两队兵隔水相望、谁也打不到谁。
2. **"伤害也要调低一点"** —— 一场会战几秒就分胜负，输的一方直接崩盘。
3. **"每个砖块都要表明属性"** —— 玩家看不出脚下这块地是水还是森林，也不知道它有什么用。
4. **"制作开始页面和功能性 UI，我还不能退出"** —— 没有开始页，也没有退出按钮。

## 决策

### 一、A* 寻路（这次是真的）

`Sim::find_path()`：网格 A*，8 邻域，斜向要求两条正交边都可走；代价 10/14，八方向启发式；
`std::priority_queue` 开表，`cost[]/parent[]` 数组闭表。

- 只对**结构目标**（塔/建筑/基地）寻路；追敌兵仍然走直线（距离近，绕路反而蠢）。
- 每个单位缓存路径（`Unit::path` + `path_target_*` + `path_tick`）：
  目标格变化超过一格、或者路径超过 40 tick（2 秒）才重算。
- 目标格不可走（基地/建筑本身）时，就近找一个可走的落点（半径 4 格内）。
- 路径点到达 48 像素内就弹掉，走完再重算。
- `stuck_ticks` 的横切兜底保留，作为 A* 失败（不可达）时的最后手段。

效果：bench 超时率 **28.7% → 20.8%**，平均对局 152.9 秒（寻路让部队真的能打到了）。

### 二、全场伤害 -25%

| 单位 | 伤害 | 塔 | 基地 |
|---|---|---|---|
| 民兵 14→**10**、长枪 20→**15**、盾卫 18→**13**、骑手 38→**28**、弓手 26→**19**、攻城车 60→**45**、巨兽 50→**37** | | 30→**22** | 45→**34** |

会战时间拉长，输一场不至于直接出局。副作用：教团（靠巨兽/法术）胜率从 9.9% 回到 **15.7%**。

### 三、每个格子都能说出自己是什么

- **鼠标悬停**：左下角实时显示脚下地块属性和数值（"森林 · 移速 -30%"）。
- **开始页的图例**：平地/道路/森林/高地/水域/岩石 六种，写清效果。
- 地块贴图本身不变（还是格子），但玩家一眼能知道踩上去会怎样。

### 四、开始页 + 暂停菜单 + 退出

- **开始页**：标题、开始游戏、退出，右侧整块图例（地形 / 资源点 / 操作）。
- **ESC 暂停**：继续游戏 / 返回主菜单 / 退出游戏。
- 之前之所以"退不出去"，是因为客户端一启动就直接连服务器，没有任何菜单；
  现在默认停在开始页，点了"开始游戏"才连接。

## 数值（bench，240 秒上限）

```
平均 149.9 秒；首次淘汰 99.8 秒；最短一局 87.1 秒；超时 17.3%
位置 15.3 / 27.3 / 28.0 / 23.3
阵营 先锋 25.2% / 商会 25.5% / 教团 14.5% / 蜂群 28.8%
```

> 蜂群这一轮又单独削了一次：占点贡献上限 3 → 2（多兵卡的"人多占得快"优势收窄）、
> 民兵 3 个减到 2 个。它从 33.3% 降到 28.8%，另外三家聚在 14~25%。

## 代价

| 项 | 说明 |
|---|---|
| A* 有开销 | 每单位最多 2 秒一次搜索，2400 格的可通行图，128 个单位时约 60 次/秒，实测无压力 |
| 蜂群仍偏强 | 33.3%：占点机制奖励人数的问题还在 |
| 开始页只有两个按钮 | 没有设置/音量/键位这些，够用但不算完整 |
