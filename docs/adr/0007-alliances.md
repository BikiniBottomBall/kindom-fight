# ADR 0007：四个联盟各一条被动

- 状态：已采纳
- 日期：2026-11
- 关系：建立在 ADR 0004（4 人局）和 ADR 0006（四资源）之上。

## 背景

四家除了颜色完全一样。玩家选完卡组就开局，"我是谁"对打法没有任何影响——
这和"四个星际联盟抢一颗星球"的设定对不上，也让组卡少了一层维度。

## 决策

四个联盟，**每家一条被动**，在构筑界面 4 选 1；三个 AI 分掉剩下的三家。

| 联盟 | 被动 | 玩起来 |
|---|---|---|
| **先锋军团** | 基地 / 塔 / 经济建筑血量 **+25%** | 更能苟，适合拖到后期 |
| **联合商会** | 物资产出 **+25%** | 贪经济，靠资源优势滚雪球 |
| **灵能教团** | 能源 **+40%**、科技 **+25%** | 法术与高级兵的路线 |
| **蜂群** | 人力上限 **+50**、人力恢复 **+25%** | 暴兵，靠数量压人 |

实现要点：

- **不用浮点**：百分比加成走"每产 1 单位攒 N 点，攒满 100 多给 1 单位"的整数累加器
  （`materiel_frac` / `energy_frac` / `tech_frac` / `manpower_frac`），和整个模拟的确定性原则一致。
- **先锋军团的加成在生成时结算**：基地、塔、经济建筑的 `max_hp` 直接乘 125%，
  所以每家的基地满血不一样 → 地图消息从"一个满血值"改成**逐家四个值**。
- **联盟随卡组一起提交**（`C2S_Deck` 末尾多一个字节），并且在地图消息里下发四家的联盟编号，
  客户端据此显示"我·先 4375 / P1·商 3500"。

## 数值（300 局 AI vs AI，每局随机分配联盟）

```
P0 19.0%  P1 28.0%  P2 23.0%  P3 25.0%   平 5.0%
对局时长 平均 128.9 秒（最短 16.6，最长 240）
首次淘汰 平均 52.8 秒
79.0% 以"只剩一家"结束，21.0% 超时

联盟胜率: 先锋 29.3% / 商会 22.3% / 教团 19.7% / 蜂群 24.2%
```

## 已知偏差（诚实记账）

1. **先锋军团偏强（29%）**。四人混战里"活下来"本身就是最大的收益：
   多 25% 血意味着前期不容易被速推，而前期被速推才是四人局最常见的死法。
   下一步要么把它削到 +15%，要么给别的联盟补一条对抗手段（比如攻城车对建筑加成再提高）。
2. **灵能教团在 bench 里偏低（19.7%），但这套测量测不到它的收益**：
   AI 卡组里一个法术、一个攻城车/巨兽都没有，能源和科技对它们几乎无用。
   这是"随机卡组 × 固定 AI"这个测量方法的盲区，不是联盟本身弱。
3. **被动和卡组的搭配没有被测**：bench 是随机卡组，测的是"联盟的平均强度"，
   不是"暴兵联盟 + 暴兵卡组"这种组合强度。组合强度只能靠人打。

## 代价

| 项 | 说明 |
|---|---|
| 又多一个选择维度 | 构筑界面多了 4 个按钮；新手可能先纠结联盟而不是卡组（"一键选推荐"已经把推荐卡组固定，联盟默认先锋） |
| 数值更难调 | 现在改一个兵种要同时看四个联盟的胜率，bench 输出多了联盟一行 |
| AI 不会用联盟优势 | 现有 AI 只按"先经济后出兵"打，不会因为自己是灵能教团就多带法术 |

## 复审条件

1. 先锋军团 > 32% → 削到 +15%，或给塔加"对攻城单位减伤"。
2. 任何一个联盟 < 15% → 先检查它的收益是否被 AI 卡组浪费，再考虑加强。
3. 超时回到 > 25% → 降基地血量（当前 3300）。
