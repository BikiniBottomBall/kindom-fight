# ADR 0005：多资源经济 + 多种降落点

- 状态：已采纳
- 日期：2026-11
- 关系：**取代 ADR 0003/0004 里"单一金币"的经济**；地图与 4 人规则沿用 ADR 0004。

## 背景

原来只有一种资源（金币，自动增长），卡牌只看一个数字。问题：

1. 没有"运营"阶段 —— 开局就是出牌对冲，和设计里"前期像传统 RTS 一样发展"不符。
2. 卡牌的差异只剩费用多少，没有任何"路线选择"：经济、科技、兵力三者没有取舍。
3. 地图只有一张、出生点固定，四家永远从同样的角出发。

## 决策

### 一、四种资源

| 资源 | 来源 | 用途 |
|---|---|---|
| **兵源** | 基地 + 兵营（+上限） | 所有单位卡的门槛，**兵力本身就是一种资源** |
| **食物** | 基地 + 农场 | 民兵 / 弓手 / 半数建筑与法术 |
| **铁** | 基地 + 矿井 | 长枪 / 盾卫 / 骑手 / 攻城车 / 火雨 |
| **科技** | 基地一丝 + 研究所 | 攻城车、巨兽、全部法术 |

卡牌价格是四元组，**四项全够才能打出**。所以"组卡"不只是选兵种，而是选你打算走哪条经济路线。

### 二、经济建筑（4 张新卡）

农场 / 矿井 / 兵营 / 研究所，各自按固定 tick 产出对应资源。
兵营还额外 +40 兵源上限（基础 120）。每人最多 6 座建筑。

为什么把建筑做成卡：它让"构筑"直接连到运营——
带两套经济卡和只带兵卡的卡组，前 30 秒是完全不同的游戏。

### 三、把运营时间压短

用户要求"主要是对战"，所以产出给得很高：

- 基地基础产出：食物 1/6 tick、铁 1/7、兵源 1/5、科技 1/60
- 农场/矿井 1/4 tick，兵营 1/2，研究所 1/6

第一个建筑 10 秒内就能落地，30 秒左右双方开始交火。
120 秒后所有产出翻倍，专门治"最后两家互相龟"的超时局。

### 四、随机降落点

三种**中心对称**的 4 点阵型（四角 / 四条边 / 内缩四角），开局随机选一种 + 随机旋转，
再按玩家序号分配。这样：

- 每个玩家这一局从哪起飞是随机的（四家都可能相邻、都可能被夹在中间）
- 但阵型本身对称，位置公平性有保证
- 降落点周围会自动清成平地（否则可能落在河里或被石头围死）

地形有两张图（`variant 0/1`）："湖与岩" 和 "双河"。客户端不自己生成地图，
服务端把格子 + 四点坐标一起下发，以后加图只改服务端。

## 数值（200 局 AI vs AI，随机卡组）

```
P0 21.7%  P1 22.5%  P2 20.8%  P3 25.0%   平 10%
对局时长 平均 136 秒（最短 22，最长 240）
首次淘汰 平均 57.7 秒
83% 以"只剩一家"结束，17% 超时
```

## 代价

| 项 | 说明 |
|---|---|
| 学习成本 | 四资源 + 建筑，比"一个金币"复杂；UI 上需要四个计数器和每张卡的多资源价格 |
| 调参维度变多 | 改一个产出会同时影响运营节奏和战斗强度，bench 必须每次跑 |
| 客户端 AI（`--bot`）不会运营 | 演示模式下"你"这个位置还是会被三家 AI 速推，截图时要趁早 |
| 没做资源上限 | 食物/铁/科技不封顶，长局会堆到几百；兵源有上限 |

## 复审条件

1. 首次淘汰 < 40 秒 → 降前期产出或提高塔/基地血量。
2. 超时 > 25% → 加产出或提前翻倍时间点。
3. 某个位置胜率 > 32% → 检查降落点阵型对称性。
